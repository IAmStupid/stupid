# Stupid

🎮 Stupid is a Steam-like platform dedicated to hosting and launching unblocked games effortlessly. Built to bypass restrictions while maintaining a sleek, library-focused user experience, it serves as your ultimate hub for gaming anywhere, anytime.🚀

# 🟧 Features 

🟧 Bypass Restrictions — Access your favorite games smoothly on school, work, or restricted networks.
⬜ Steam-Like Interface — Enjoy a clean, dark-themed dashboard featuring game cards, categories, and smooth navigation.
🟧 Massive Game Library — Explore a wide variety of pre-unblocked titles, from casual web games to retro emulation classics.
⬜ Cloud Saves & Favorites — Keep track of your progress and build your personal collection using local or cloud storage.
🟧 No Downloads Required — Launch games directly inside your browser with optimized loading speeds and minimal resource usage.

# 🛠️ Tech Stack

⬜ Frontend: HTML5, CSS3, TailwindCSS, JavaScript
🟧 Backend: Node.js / Express (or your specific backend)
⬜ Proxy Integration: Clean routing and security layers to ensure maximum uptime
